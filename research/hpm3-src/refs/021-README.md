Independent current-epoch trial-bank acceptance source

FM owns the isolated producer and its current-worker/HPO/default-OFF integration.
This packet owns one semantic acceptance contract and one independent fixture
entrypoint. It introduces no production encoder, bank, consumer or controller.

The twelve prepared methods call the real `automl.infrastructure.hpo_bank` API.
Their future fixtures use only temporary synthetic byte files and closed metadata
descriptors. They do not instantiate an estimator, import NumPy/pandas, inspect
task data, call a provider, or read a historical trial bank. The test runner must
bind the exact reviewed candidate package; silently importing a canonical or
historical helper would test a different source.

The contracts cover typed identities; ordered prepared/native/effective evidence;
before/after snapshots; incomplete receipts; real-parent object authority;
exclusive current-epoch admission; anchor and producer-only accounting; rejected
objective/parent/source/deadline cases; sealed-artifact and receipt tampering; and
late index durability failure. A bank rejection must leave its own objective NULL
without rewriting the original HPO callback/value. No entry is reusable here.

These mocks do not establish actual NumPy/pandas/native-model adapter identity,
default-OFF integration equivalence, or runtime source/cleanup observations.
Those require the separately reviewed producer bridge, its source fixtures and a
future authorized technical run. Existing HPO/LOSS golden methods, assertions and
literal witnesses remain an independent integration requirement.

Current status: interface source is being coordinated with FM. No test module or
candidate was imported or executed by this author. Actual tests, fits, API calls,
data-array reads and consumer/cache-hit/warm-start/savings measurements are zero
or unavailable as declared in the acceptance contract. No runtime READY or clock
has been assigned to this packet.
