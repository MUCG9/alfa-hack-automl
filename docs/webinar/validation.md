# Проверка разбора и передачи

## Итог: можно передавать с оговорками

Сопоставлены полный транскрипт, повторное ASR ключевых фрагментов, код v2, public-измерения, снимок score и повтор синтетических диагностик. Решение поддерживает именно приоритизацию следующего этапа; не доказывает будущие private-баллы.

## Проверки и ограничения

- Отношение карточек пересчитано: 1694.145 / 857.742 = 1.9751218898, прирост 97.51218898%. Не приравнивается к отношению качества моделей.
- JSON-аудит воспроизведён из сохранённого ZIP; все 14 записей совпали с исходным аудитом. Пять ранних отказов + пять semantic/split пробелов, четыре удовлетворяют проверяемому loader-контракту. Это не оценка процента private-провалов.
- Корневой код сопоставлен с архивом побайтно. После распаковки ZIP повторно пройдены 11 unit + 7 resilience + 5 smoke: 23. Реальные API-запросы в этой проверке не выполнялись. Результаты — `docs/handoff_verification.json`.
- SQL public_metrics.sql реально выполнен в SQLite JSON1 над v2_results.json; он извлекает восемь записанных измерений для двух отдельных графиков. Поля search42 и fixed-recipe44 не названы равноценной CV. Reviewed rows — `reviewed_metrics.json`.
- Канонический HTML прошёл validation/package/structural verification. Compatible Chromium отсутствует: интерактивность source dialog, светлая/тёмная тема и narrow layout браузером не проверены; HTML сохраняет semantic fallback. Это ограничение QA оформления, не подмена измерений.
- Полной ручной дословной проверки ASR нет; неясные ответы не превращены в гарантии. Дата эфира и календарный deadline не выведены из контейнера MP4/фразы «неделя».
- Не определены scale преобразования upload-card/leaderboard, отдельные серверные метрики и baseline. Не вычисляется вымышленный v2 leaderboard score.
