## Полученные наблюдения

На search-срезе V11 в классификации контрольный ансамбль имеет Macro F1
0.6632403174648631. Фиксированные абляции (без переобучения и подбора весов)
снижают его при удалении первого LGBM feature-view участника на 0.008090480,
второго на 0.000914460, XGBoost на 0.008861189. Эти значения относятся к одному
search-разбиению, не доказывают устойчивость вклада и не разрешают менять состав.

Слабые классы: Backdoor F1=0.214634146, Analysis F1=0.342507645. Из 158 Backdoor
115 предсказаны как DoS, из 211 Analysis — 129. Для Worms всего 19 validation-строк:
его F1 не следует трактовать без поддержки. Найдены 1458 групп одинаковых полных
признаков с конфликтующими метками (14829 строк исходного train). Это описание
группировки, не теоретический предел достижимого Macro F1.

В регрессии search RMSE=38.902803731334785, MAE=20.520273691, средняя ошибка
prediction-minus-target=+5.386067067. Верхний 1% абсолютных ошибок даёт 45.7242%
суммы квадратов ошибок, верхние 5% — 67.6113%.

Контекст `(facility_type, floor_area, State_Factor, building_class)` отсутствует в
fitting-части для 5517 из 18308 validation-строк: RMSE 61.487746426 и 75.2796% общей
SSE. При добавлении year_built — 5673 строки, RMSE 61.805957104 и 78.2115% SSE.
Это пересекающиеся срезы. Количество предшествующих периодов является прокси
покрытия контекста и не устанавливает фактическую пригодность history-признака
конкретной модели. Связь с ошибками описательная, причинный эффект не измерен.

Для regression search присутствует один validation-период (Year_Factor=5).
Доверительные интервалы по независимым временным блокам построить нельзя: uncertainty
явно unavailable. Подмена временного bootstrap построчным не выполняется.

Эти наблюдения задают вопросы для последующего SEL-01: вклад похожих рецептов,
поддержка редких классов и ошибки на невидимых контекстах. Протокол новой гипотезы
и confirmation-диагностика нужны до любого обучения или изменения политики.
