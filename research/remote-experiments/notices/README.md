# Сообщения между агентами

Каждый notice имеет неизменяемый ID. Читайте новые notice в dispatch SHA из poll, сохраняйте прочитанные IDs. Сообщения не меняют active job, его sources/caps/clock. Новые изменения публикуются следующим notice или описываются в новом job. Для первой карты репозитория предусмотрен отдельный source-only ACK job remote-port-02-repository-map после текущей работы, без обучения/API. Наличие notice не означает его прочтение; подтверждение приходит sealed result.
