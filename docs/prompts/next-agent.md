До получения данных и API-секретов продолжай offline fixtures. На прежнем ПК мало свободной RAM; несколько тяжёлых прогонов одновременно не запускать. Данные, окружение и Qwen API key в Git отсутствуют; запроси у капитана недостающие материалы/приватное окружение, не проси ключ в общем prompt и не читай посторонние credentials.

Затем по измерениям выбери одно наиболее перспективное улучшение. В приоритете эффективность search и редкие классы/calibration/ensemble; не менять метрики и splits ради числа. Для augmentation нужен copy-only control; не считать SMOTENC, pseudo-labeling и multi-target/ranking уже реализованными. Каждая политика обучается только внутри fitting rows, lineage synthetic объектов не пересекает validation. Не добавляй runtime dependencies, GPU-аренду или новый distributed stack без отдельного согласования.

Работай самостоятельно, без запуска дополнительных ChatGPT-агентов и сообщений другим чатам. Сохраняй предыдущие релизы, чужие изменения и текущие секреты. После каждого логического изменения — проверки, воспроизводимые измерения, отдельный commit и краткий evidence-backed отчёт. Сообщай о конкретных внешних блокерах; не выдавай неполный прогон за успешный.
