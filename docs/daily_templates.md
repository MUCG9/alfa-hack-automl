# Шаблоны отчётности и решений

## Личный отчёт

```text
Дата / имя / роль / issue:
Версия общего контекста и commit:
Проверенная гипотеза (один изменяемый фактор):
Данные / split hash / evaluator:
Команда запуска и фактический статус:
Метрика baseline / experiment / направление улучшения:
Время / пиковая память / Qwen tokens или общий счётчик:
Артефакт, лог, diff:
Вердикт: keep / reject / inconclusive
Блокер и кто должен решить:
Следующий результат / срок:
```

## Сводка капитана

```text
Дата / версия release:
Готово и независимо проверено:
Интегрировано, но ещё не проверено:
Таблица сопоставимых метрик (не смешивать split):
Открытые P0 / владелец / срок:
Расход общего dev budget / оставшиеся submit-слоты:
Официальный статус и время последнего наблюдения:
Следующее решение капитана:
Один результат на завтра у каждого:
```

## Decision log

```text
ID / дата / автор:
Вопрос и варианты:
Факты / источники / что неизвестно:
Решение и причина:
Затронутые модули / prompts / владельцы:
Критерий отмены решения:
Срок перепроверки:
```

## Перед отправкой

```text
Версия / commit / SHA-256 ZIP:
Что изменилось относительно предыдущей:
Локальный эффект на том же split:
Какие проверки реально пройдены:
Что осталось непроверенным:
Ожидаемый сигнал от платформы:
Кто разрешил расход слота:
Время отправки / оставшиеся попытки:
Видимый статус / официальный score (пусто, пока нет):
```
