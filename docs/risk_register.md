# Актуальный реестр рисков

Версия 21 октября. Владелец P1/P2/P3/P4/P5 соответствует `team_workflow.md`. Оценки вероятности и влияния качественные, а не измеренные частоты. «Снижен» не означает «исключён».

| ID | Приоритет | Риск и ранний сигнал | Что уже сделано | Следующее действие и владелец |
|---|---|---|---|---|
| R01 | P0 | Private содержит неизвестную схему или текст | Новые имена полей, числовые labels и synthetic text прошли smoke | Реальный text holdout, вероятность/несколько target, явный unsupported contract; P2 |
| R02 | P0 | JSON отсутствует из-за reasoning/truncation | max_tokens 8192, обработка ошибок, deterministic fallback | Адаптивный budget и записанные failure traces; P1/P5 |
| R03 | P0 | Best теряется при timeout или final fit | Ранний файл, worker timeout, атомарная замена | Failure-injection: kill worker, нехватка времени, API 429; P1/P2 |
| R04 | P0 | Public улучшение не переносится на private | Нет ручных веток по названию датасета | Проверять переносимость каждого recipe и ограничивать поиск по holdout; P2 |
| R05 | P1 | Классификация завышена точными дубликатами | Один grouped holdout, общих feature-hash нет | Сравнить random/group, несколько folds; P4/P2 |

| R08 | P0 | Среда платформы отличается от локальной | Исходный requirements, Python 3.12, распаковка и запуск ZIP | Дождаться официального статуса, при ошибке запросить admin logs; P1/капитан |
