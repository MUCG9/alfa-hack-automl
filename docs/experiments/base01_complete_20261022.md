# BASE-01 и ERR-01 завершены

22 октября 2026. Ветка `work/error-profile-contracts-20261022` сохранена.
По поручению капитана закрыты первые два этапа основного плана: проверенный
baseline V11/V16 и полный компонент паспорта ошибок. Обучение, подбор весов,
изменения Search, новый релиз и submit не выполнялись.

- [Закрывающий receipt BASE-01](base01_verified_20261022.json): восемь паспортов,
  контрольные метрики всех четырёх исходных запусков и фактические SHA итоговых CSV.
- [Confirmation-диагностика](error_passport_confirmation_20261022.json) и
  [сохранённая search-диагностика](error_passport_search_20261022.json).
- [Инкрементальный перенос](error_passport_transfer_complete_20261022.json):

  485 уникальных объектов. Прежние 848 файлов и их mtime сохранены. Четыре
  добавленных NPZ совпали с SHA и сигнатурами из исходных split JSON.
- [100 целевых проверок](error_passport_verification_restored_20261022.json)
  пройдены ранее; текущие canonical compiled source и test scripts побайтно
  соответствуют этому gate. Повторно запускать неизменившуюся suite не требовалось.
  Обновлён только upstream-восстановитель; реальный verify/restore и отрицательная
  проверка старого неполного manifest прошли. Прежние 54 файла сборки не менялись.

Выполнены только четыре недостающих confirmation-паспорта; четыре search-паспорта
переиспользованы после проверки их запросов, всех исходных ссылок и разделов.
Каждый анализ запускался последовательно в owned subprocess с лимитами
600 секунд / 1536 MiB / один поток. Полные локальные отчёты находятся в
`test-runs/error-passport-20261022/base01-complete/` и `base01-restored-search/`.
Исходные JSON не переписаны; используется отдельный root_mapping. Кэши V10 и
реконструкция разбиений не применялись. Исходные prediction CSV/NPZ в Git не добавлены.

Для V11 и V16 совпали все индивидуальные модельные диагностики в обоих scopes
и фактические итоговые CSV. Это воспроизведение сохранённых прогнозов, не прирост
метрик, не независимое подтверждение и не официальный score. Среднее двух reused
public cuts не является pooled OOF; runtime search+confirmation не полная CV.

Четыре классификационных паспорта имеют status=complete. Четыре регрессионных —
partial только из-за uncertainty=unavailable: на каждом временном срезе один
validation-период. Alignment, models, comparisons и slices во всех восьми
паспортах complete; failed-разделов нет. Построчный bootstrap вместо временных
блоков не применялся. R² для singleton-срезов не определён и сохранён как null,
низкая поддержка отмечена; RMSE таких срезов вычисляется.

## Что выяснилось о классификации

Все три участника выбранного ансамбля дают положительный вклад на обоих
сохранённых срезах. Ниже изменение F1 после удаления участника с нормировкой
оставшихся фиксированных весов, без переобучения и оптимизации:

|Удалённый участник|Search: Δ F1|Confirmation: Δ F1|
|---|---:|---:|
|Основной LGBM feature views|−0.008090480|−0.001358397|
|LGBM feature views, seed=48|−0.000914460|−0.002381926|
|XGBoost с decision calibration|−0.008861189|−0.001094887|

При этом на confirmation корреляция индикаторов ошибок двух LGBM равна
0.948526867, корреляция всех вероятностных значений — 0.999263452. Первый
правильно решает 126 строк, где второй ошибается; второй — 146 строк, где
ошибается первый. У пар LGBM/XGBoost корреляция ошибок ниже: 0.912765760 и
0.896421987. Высокая корреляция сама по себе не доказывает бесполезность участника.
Критерий полезности должен учитывать целевую метрику и вклад в смесь.

Backdoor: F1 0.214634146 / 0.237288136; Analysis: 0.342507645 / 0.272727273
на search / confirmation. Для Worms всего 19 / 11 validation-строк; колебания
его F1 требуют осторожной оценки поддержки. Найденные 1458 групп одинаковых
полных признаков с конфликтующими метками не являются готовой границей Macro F1.

Абляции описательны: эти модели уже отбирались на reused public данных.
Bootstrap-интервалы относятся к фиксированным индивидуальным прогнозам против
контроля; отдельные интервалы значимости абляций не строились. Интервалы не
скорректированы на множественные сравнения и не учитывают новые fits/private test.

## Что выяснилось о регрессии

|Диагностика|Search|Confirmation|
|---|---:|---:|
|Средняя ошибка prediction−target|+5.386067067|−1.749959909|
|Доля SSE от верхнего 1% ошибок|45.7242%|59.8942%|
|Доля SSE от верхних 5% ошибок|67.6113%|80.0395%|
|Доля SSE невидимого базового контекста|75.2796%|54.2174%|
|Доля SSE невидимого контекста с year_built|78.2115%|57.3140%|

Базовый контекст — набор `(facility_type, floor_area, State_Factor, building_class)`.
Невидимость определяется только fitting-строками соответствующего среза. Срезы
пересекаются и не складываются. На confirmation базовый контекст не встречался
для 2616 из 12946 строк (RMSE 52.402857507); с year_built — для 2821 строк
(RMSE 51.883982590). На search соответствующие RMSE — 61.487746426 / 61.805957104.

Концентрация больших ошибок и связь с отсутствующим контекстом наблюдаются на
обоих срезах. Это описательная связь, а не измеренный эффект конкретного нового
метода. Среднее смещение меняет знак: перенос одной поправки между срезами не
обоснован этими данными. Закрытые отрицательные V15/V16 не перезапускались.
