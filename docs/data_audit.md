# Аудит исходных материалов и пригодности данных

## Вывод

Данные пригодны для первой реализации с оговорками. Главные ограничения честного сравнения — точные feature-дубликаты и редкие классы в classification, а также сдвиг пропусков в regression. Это не доказательство временной или смысловой утечки. В комплекте есть воспроизводимый notebook `public_data_audit.ipynb` и его модуль `audit_public_data.py`; исходные CSV нужно взять у организаторов.

## Происхождение материалов

В проверенном ранее исходном ZIP — 12 файлов, 86 706 697 байт после распаковки: baseline, requirements и по пять файлов двух задач. SHA-256 исходного архива: `df6feb6f3efa8959954b918b4a458b989636779ccb46b3516b1b909856cc0765`. PDF содержал 20 страниц. Временные пути исходных загрузок сейчас недоступны, поэтому архивная целостность здесь опирается на сохранённый аудит 19 октября, а профиль CSV повторён по рабочим копиям 21 октября.

Единица анализа: строка здания для regression, строка сетевого наблюдения для classification по описаниям задач. Нет подтверждённых entity/time-ключей, позволяющих автоматически объявить random split «правильным» для любого private.

## Схема и проверки

| Проверка | Regression | Classification |
|---|---:|---:|
| Train | 53 308 × 64 | 87 670 × 44 |
| Test | 22 449 × 63 | 41 166 × 43 |
| Число признаков без id/target | 62 | 42 |
| Sample: число строк и порядок id | совпадают | совпадают |
| Train/test: набор и порядок признаков | совпадают | совпадают |
| Target null | 0 | 0 |
| Пересечение train/test id | 0 | 41 166 |

Проверены null/inf, schema/dictionary, id, категории, label counts, feature hashes и конфликтующие ответы. Hash совпадения — диагностика точного равенства, не поиск всех смысловых дубликатов. Наивная склейка classification по id недопустима: совпадение id не доказывает совпадения объектов.

## Существенные находки

| Риск | Доказательство | Влияние и серьёзность | Действие |
|---|---|---|---|
| Classification duplicates | 33 442 строки train повторяют ранее встреченный feature-вектор; 5 816 повторных hash-групп | Высокий: обычный random split может завышать качество, уверенность в факте высокая | Сравнить stratified/group; v1 использует grouped holdout |
| Противоречивые labels | 1 458 feature-групп, 14 829 строк train; 786 test-строк совпадают с неоднозначными train-группами | Высокий: точное совпадение признаков не гарантирует ответ | Не считать lookup безошибочным, измерять per-class |
| Редкий Worms | 65 строк, 0.0741% train | Высокий: Macro F1 нестабилен, один holdout недостаточен | Несколько folds/seed, число объектов рядом с F1 |
| Новые категории state | ACC и CLO только в test | Средний: возможен сбой encoder | Unknown handling и synthetic contract test |
| Пропуски regression | energy_star_rating 41.69% train против 19.99% test; direction_peak_wind_speed 50.72% против 65.81% | Высокий: random holdout может не отражать test | Missing indicators, ablation и срезы |
| Regression неоднозначные feature-группы | 243 группы с разными target, 538 строк | Средний: недостающие признаки/шум возможны, причина не установлена | Не удалять автоматически, проверить устойчивость |

## Baseline и окружение

Официальный baseline синтаксически корректен, но импортирует `mcp`, отсутствующий в фиксированном окружении. Организатор подтвердил отсутствие пакета. V1 реализован без него. Baseline не задаёт полноценный цикл отбора best и общий deadline. В task.md есть вложенные пути: v1 использует resolver, обе public задачи реально запущены.

Оригинальный requirements содержит 39 закреплённых строк. Файл v1 побайтово совпал с актуальным файлом платформы: SHA-256 `9173b0388532fbd2a709e4f4b3029e3b9ccab685fce43a85261ffa1ba95efbe6`. Локально установлены используемые библиотеки, но полный Docker и весь тяжёлый комплект не воспроизводились. Официальный запуск ещё проверяется.

## Ограничения и автоматические проверки

Не проверены скрытые targets, private и смысловая/временная утечка по неизвестному происхождению данных. Нет основания удалять все дубли или заявлять статистически устойчивый прирост по одному split. Стабильные проверки для CI: схема, id/order sample, отсутствие null в target/id, допустимые labels, finite predictions и отсутствие общих feature-hash в выбранном grouped split.

Для повторения откройте notebook из этой папки с установленными pandas/numpy, задайте `PUBLIC_TASKS_DIR` корнем разрешённых данных с вложенными путями задач и выполните все клетки сверху вниз. Notebook не вызывает Qwen и не передаёт данные в сеть. Выход — компактные сводки, полный профиль в `dataset_profile_rechecked.json`.
