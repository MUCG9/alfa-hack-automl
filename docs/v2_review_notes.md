# Review v2: замечания проверяются, а не принимаются на веру

Qwen использован и для генерации гипотез, и для review нового кода. Сохранены исходный ответ и расходы в локальном `outputs/v2-research/`. Это внешний автоматический review, не сертификат корректности.

Результат независимой проверки замечаний:

| Замечание | Решение и доказательство |
|---|---|
| В низкоуровневом worker можно передать `nested_stopping=False` и использовать search holdout для stopping | Этот режим оставлен для сравнения с v1 в исследовательских скриптах. Production-портфель и ответы Qwen проходят `normalize`, который принудительно включает inner stopping; fallback наследует его. Это проверено тестом. Прямой вызов worker с экспериментальным рецептом не имеет таких гарантий. |
| Binary AUC якобы меняется на `1-AUC`, если поменять положительный класс | В таком виде утверждение неверно: одновременное обращение метки и вероятности сохраняет AUC. Worker передаёт фактический порядок `model.classes_`; ensemble отдельно выравнивает столбцы. Семантика единственного вероятностного столбца всё же должна быть согласована с условием: сейчас используется второй класс в строковой сортировке. |
| Ensemble неверно обрабатывает порядок столбцов sample | Код уже переставляет вероятности в порядок sample. Дополнительно проверен реальный ensemble с обратным порядком имён классов. |
| Дубликаты могут пересекаться в grouped split | В public-классификации зафиксировано нулевое пересечение хешей; test-case и отчёты позволяют это проверить. Регрессионный random holdout имеет совпадения признаков — он не называется group-independent. Редкие группы могут вызвать явно отмеченный fallback. |
| AST-фильтр недостаточен как security sandbox | Согласны с ограничением. Прямые `np.fromfile`/`loadtxt`, `pd.ExcelFile` и подобные функции могли обходить простой список I/O-запретов; добавлены whitelist функций модулей и тесты отказа. Полной security sandbox это не делает. |
| Минимум 100 итераций универсально оптимален | Такого утверждения нет. Это ограничиваемый гиперпараметр, предотвращающий случайный ранний пик F1 на маленьком inner holdout. Qwen может предложить `min_iterations` от 1; общий выбор проверяется на другом split. |

Дополнительно обнаружено и исправлено без подсказки review: допустимость log-target проверялась по минимуму target на всех train-строках, включая search validation. Теперь только по fitting rows. Тест меняет исключительно внешние метки и проверяет неизменность выбранного числа деревьев и test-прогнозов.

В старом AST-фильтре также запрещались все атрибуты `to_*`, включая безопасный `pd.to_numeric`. Для явно разрешённых преобразований pandas сделано исключение: корректный feature-код больше не отвергается по этой причине.

Общее правило для команды: сначала воспроизводимый контрпример или числовая абляция, затем правка. Длинное убедительное рассуждение ИИ само по себе не доказывает баг или рост качества.
