Before fitting, freeze the task/metric contract, control and candidate source,
allowed input hashes, ordered split indices, one changed factor, acceptance rule
and all-inclusive resource limits. Clock assignment happens once at actual launch.
Failures keep null metrics and their first and subsequent errors. Recovery inherits
the original budget where the declared protocol requires it.

Choose group/forward/IID splits from task provenance. Fit transforms, target
statistics, selectors and calibration exclusively on fitting rows. Paired models
use identical saved rows and class order. Target metrics determine ranking; other
metrics remain diagnostics. Unknown objectives block objective-dependent search.

Search and audit are distinct. Repeatedly reused public cuts are adaptive search
evidence. New audit access is a shared quota across agents, with three to five
finalists at most under an explicitly declared protocol. Audit errors do not feed
new hypotheses. Full CV requires exactly-once OOF coverage and an explicit fold
mean versus pooled distinction. Evaluating a fixed winner does not evaluate the
entire adaptive search procedure.

Parent-sealed core artifacts must exist before pristine truth is read. Independent
verification checks probabilities, class/row order, finite outputs, recursive
recipe/iteration evidence, CSV integrity and input/source posthashes. Technical
completion, quality improvement and audit completeness are separate fields. Full
agent qualification also requires actual stages, Qwen ledger/usage, completed HPO
attempts, final refit and output CSV. Source-only or mocked checks provide none of
these ML claims.

Local heavy fits, fixture suites and heavy auditors remain serial. Worktree source
development can overlap the immutable active run; its files may not change. Each
writer has an exclusive scope. Tests need a root-recorded lease with CPU, RAM,
timeout, process identity and cleanup receipt. Do not signal a reused or unknown
PID. Sampled subtree memory is not an OS hard cap or complete host attestation.

Windows and Linux can fit in parallel on separate hosts after each host's own
admission gate. Remote sources are reviewed before execution; scalar metrics and
resource receipts remain remote-reported until independent verification or local
confirmation. No private rows, predictions, weights, credentials or absolute paths
are transferred through Git. Exact remote job/worker/source/approval bindings are
required before a bounded model job is claimed.

For this development wave, unit failure cases include unknown/conflicting metrics,
failed atomic writes preserving the last result, malformed checkpoint schema,
missing capabilities, strict process traversal denial, PID reuse and terminal or
cleanup observations after the original deadline. Prepared cases are not passed
cases until actual guarded execution and cleanup are recorded.
